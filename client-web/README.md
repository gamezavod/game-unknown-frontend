# Свой остров · Первый берег

Браузерный прототип: Vite, TypeScript, Three.js / WebGL, HTML и CSS. Семь low-poly гексов, море, свет, вращение и приближение камеры, выбор клетки и правая панель. Без UI-фреймворков.

## Запуск

Node.js 22.12+ (проверено на 24), npm и браузер с WebGL 2.

```bash
cd client-web
npm ci
npm run dev
```

Откройте адрес из терминала (обычно http://localhost:5173).

```bash
npm test
npm run build
```

Сборка: `dist/`. Для её локальной проверки: `npx vite preview`.

## Управление

Перетаскивайте левой кнопкой для вращения; колесо изменяет масштаб. Короткий клик выделяет клетку. Кнопки координат в панели доступны через Tab и Enter. «Вернуть камеру» восстанавливает ракурс.

## Структура

- `src/data/cells.json` — семь клеток, координаты q/r, тип, состояние, высота.
- `src/hex.ts` — осевые координаты pointy-top сетки → плоскость XZ; Y — высота.
- `src/hex.test.ts` — один тест центра и расстояний шести соседей.
- `src/main.ts` — сцена, декорации, камера, raycasting, панель.
- `src/style.css` — адаптивный интерфейс.

Визуальная основа — концепция «Свой остров». Полная карта, экономика, строительство, match-3, сервер и сохранения за пределами первого прототипа.

Модели гексов, побережья, деревьев и горы — из предоставленного набора KayKit Medieval Hexagon Pack. Используемые glTF, бинарные данные и текстуры находятся в `public/kaykit/`; отдельного файла лицензии в предоставленном архиве Assets.zip нет.

# Свой остров · Первый берег

Первая версия 3D-карты для мобильной браузерной игры: Vite, TypeScript, Three.js / WebGL 2, HTML и CSS. Остров из 67 hex-клеток: открытая центральная поляна, 14 лесных участков, пять гор, выраженный обрыв с песчаной полкой и мелководьем, глубокое море и пять стартовых зданий. 13 неисследованных клеток скрыты плотным мягким туманом; новых механик исследования нет. Интерфейс на русском, без UI-фреймворков.

## Запуск и проверка

Node.js 22.12+ (проверено на 24), npm и браузер с WebGL 2.

```bash
cd client-web
npm ci
npm run dev -- --host 0.0.0.0
npm test
npm run build
npx vite preview --host 0.0.0.0
```

Разработка: http://localhost:5173. Production preview: http://localhost:4173. На телефоне в одной сети откройте сетевой адрес из терминала. Сборка сохраняется в `dist/`.

## Управление

- Один палец или левая кнопка мыши: перемещение карты по земле, без вращения.
- Два пальца: масштаб и перемещение. Колесо мыши или кнопки +/−: масштаб.
- Короткий тап/клик: выделение клетки и сведения об участке. Перетаскивание, долгое нажатие, отмена жеста и мультитач не выбирают клетку.
- Кнопка ⌖: вернуть весь остров в исходный изометрический ракурс. Ортографическая камера вписывает фактический 3D-объём острова с запасом воды вокруг, учитывает высоту зданий и перестраивается при изменении размера экрана. Границы перемещения рассчитываются из данных карты.
- «День / Ночь»: плавная смена освещения. «Автосмена» на большом экране переключает фазу каждые 35 секунд активного времени.
- Информация об участке находится в компактной нижней карточке. Список клеток открывается по кнопке «Участки». Клавиатура: список, кнопки и переключатели доступны через Tab. На canvas стрелки перемещают карту, +/− меняют масштаб, Home возвращает камеру.

## Данные и подключение API

- `src/data/cells.json` — статическая тестовая карта, не генератор. Массив клеток с координатами `q`, `r`, местностью `type`, высотой поверхности `height`, состоянием `state`, необязательными `building`, `rotation` (градусы) и `variant` (вариант декоративной модели 0–2).
- `src/map-data.ts` — типы DTO, проверка данных, интерфейс `MapSource`, локальный и HTTP-источники, расчёт рамки карты.
- `src/hex.ts` — осевая pointy-top сетка → плоскость XZ, вертикальная ось — Y.
- `src/island.ts` — загрузка моделей, отображение клеток, трёх вариантов леса/гор, песчаного берега и выделения. Модели и текстуры повторно используются клонами.
- `src/camera.ts` — вписывание объёма карты в экран, с запасом под интерфейс.
- `src/atmosphere.ts` — море с переходом от мелководья к глубине, блики и пелена над клетками `unexplored`. Берег и туман следуют данным карты.
- `src/gestures.ts` — фильтрация тапов и мультитача.
- `src/main.ts` — сцена, камера, атмосфера, время суток, raycasting и UI.

Для API замените `demoMapSource` на `httpMapSource('/api/map')` в `main.ts` (или передайте свой объект `MapSource`). Сервер возвращает тот же массив; рендерер не зависит от количества клеток и расположения острова относительно начала координат. Сейчас данные загружаются при открытии страницы; потоковые изменения карты и реальный сервер не входят в эту версию.

```json
[{"q":0,"r":0,"type":"grass","height":0.65,"state":"visible","building":"townHall","rotation":0}]
```

Местности: `grass`, `forest`, `rock`, `coast`, `water`. Состояния: `visible`, `unexplored` (скрывает декорации, показывает нейтральный гекс). Высота — неотрицательное число в единицах сцены. Координаты — уникальные целые числа. Здания: `townHall`, `home`, `lumbermill`, `farm`, `warehouse`. Стартовые здания декоративные, без игровой логики. Туман отображает состояние `unexplored`, меняет оттенок ночью и не открывает клетки; механики исследования нет.

## Ассеты и ограничения

Модели — из предоставленного архива KayKit Medieval Hexagon Pack. В `public/kaykit/` сохранены используемые glTF, связанные `.bin` и PNG. ZIP в проект не добавлен. Новые здания используют красный вариант моделей; модель церкви представляет ратушу, рынок — склад, поле зерна — ферму. Отдельного файла лицензии в предоставленном архиве нет.

Строительство, ресурсы, экономика, match-3, генерация, сохранения и сервер не реализованы. Производительность на физических телефонах требует отдельного замера: браузерная проверка использует эмуляцию touch/viewport в Chromium. DPR ограничен 1.75; эффекты воды и дымки обходятся без постпроцессинга. Vite предупреждает о размере основного JS-бандла Three.js (около 616 КБ до gzip).

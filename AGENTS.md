# Правила проекта

- Клиент находится в `client-web`: Vite, TypeScript, Three.js, HTML и CSS. Не добавляйте React и другие UI-фреймворки.
- Используйте существующий checkout; не создавайте worktree без прямого запроса пользователя.
- Данные клеток храните в `client-web/src/data/cells.json`, геометрию координат — в `src/hex.ts`. Осевая сетка: q, r; вертикальная ось сцены — Y.
- Сохраняйте разделение данных, вычислений и отображения. Интерфейс и документация — на русском.
- Не добавляйте механику из концепции за пределами согласованной задачи.
- Устанавливайте зависимости через `npm ci` при наличии lock-файла. Коммитьте package-lock.json при изменении зависимостей.
- Перед завершением запускайте из `client-web` команды `npm test` и `npm run build`.
- Не коммитьте секреты, node_modules, dist и временные результаты проверок.
